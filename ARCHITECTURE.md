# hana — Architecture

**hana** (花) is a modular X11 window manager with a native status bar, written in Zig. It manages windows both by tiling and floating, brings its own composited bar (segments are drop-in addons), and is designed so that optional subsystems can be compiled out while the core keeps working unchanged.

This document walks the codebase file-by-file: what each file is for, what it depends on, and the architectural seams that hold the whole thing together. Generated by reading `src/` in full.

---

## 1. Design philosophy

The central idea is **hub-and-spoke composition**: a small, always-compiled core at the center (one pure model, one event pipeline, one sync boundary) with optional subsystems hanging off it through **build-generated registries** bound against the **open contracts** defined in `src/core/contract.zig`.

Four properties fall out of this design:

- **Build-time auto-discovery.** `build.zig` walks the source tree; every `.zig` file under `src/` becomes a named module, and every `modules/` directory becomes a deterministic registry. `has_*` build flags are *derived from the walk*, never hand-maintained, so a flag can never disagree with what is actually on disk.
- **The core never names an optional subsystem.** Core, input, and sync reach tiling/bar/window-addons only through generated seams (`tiling_seam`, `surfaces`) and generated registries (`tiling_modules`, `window_modules`, `bar_modules`, `systatus_subs`, `slider_subs`, `prompt_subs`, `title_subs`). Dispatch loops iterate the registry; deleting a file just shrinks the array and turns hook calls into no-ops.
- **A pure, allocator-free model.** `src/model/model.zig` is the single source of truth for management state — no X11, no allocation, no feature-specific imports. Layer purity is *enforced at build time* (`assertPureLayerImports`), not just documented.
- **One sync boundary.** "Planning in `sync.zig`, dispatch in `sink.zig`, raw XCB in `wire.zig`": the reconciler computes everything unconditionally and sends only the delta, under a server grab, in exactly one flush.

Terminology used throughout:

- **contract** — the interfaces declared in `src/core/contract.zig` (`Surfaces`, `WindowModule`, `Layout`, `Segment`, the `tiling_mods` conditional import). Open to any module that binds `pub const module`, closed to extension by the core.
- **contractor (module)** — any file inside a `modules/` directory that binds one of those contracts via a comptime-structured `pub const module` declaration and is pulled into a generated registry. Dispatch is registry-first; nothing names a sibling module.
- **core** — the always-compiled layer: `core.zig`, `contract.zig`, `pipeline.zig`, `events.zig`, `persist.zig`, `restart.zig`, `scale.zig`, `screen.zig`, the `sync/`/`x11/` seam, and the shared utility shelf.
- **model / config** — the two pure layers (no `xcb`), kept free of X by construction and enforced by the build.
- **other** — file/service modules that are neither contract nor core: `main.zig`, `signals.zig`, `spawn.zig`, layout helpers such as `tiling/tiling.zig`, bar helpers such as `bar/segment.zig`.

## 3. Build system (`build.zig`)

`build.zig` is large and is where much of the architecture is *mechanically enforced*.

### 3.1 Module discovery

- `Module.DiscoveryContext` walks `src/`. Every `.zig` file becomes a build module named by its stem; every file under a `modules/` directory becomes an **owner registry member**; sibling files under a package directory become a **sub-registry** (`<package>_subs`). Stems are sorted for deterministic dispatch order.
- `has_*` flags are derived from `discovery.modules`:
  - `has_tiling = discovery.modules.contains("tiling")`, `has_floating`, `has_minimize`, `has_fullscreen`, `has_workspaces`, `has_drawing` (drawing infrastructure), `has_bar_win`, `has_bar_segment`, `has_bar_orchestrator`, `has_bar` (whole bar), `has_vim` (prompt's vim addon), `has_seg_prompt`, `has_layout_scroll` (scroll layout hooks), etc.
- A panic occurs if neither `tiling` nor `floating` is present — a WM needs at least one window mode.

### 3.2 Generated modules / registries

- `surfaces` — `if (build_options.has_bar) @import("bar").surfaces else null`; the chrome-surface (bar) interface reachable by core without naming the bar.
- `window_modules` — array of all `contract.WindowModule` bindings from `src/window/modules/`.
- `tiling_modules` — array of all `contract.Layout` bindings, emitted like:
  ```zig
  pub const modules = [_]contract.Layout{
      @import("fibonacci").module, @import("grid").module, @import("leaf").module, ...
  };
  ```
- `tiling_seam` — `pub const tiling = if (build_options.has_tiling) @import("tiling") else struct {};` Core/input import this seam, never `src/tiling/` by name.
- `bar_modules` — array of all `contract.Segment` bindings from `src/bar/modules/`.
- `<pkg>_subs` — `systatus_subs` (batt/cpu/mem readouts), `slider_subs` (brightness/volume), `prompt_subs` (vim addon), `title_subs` (carousel scroller).
- `fallback_toml` — `pub const content = @embedFile("fallback.toml");` from `config/fallback.toml` (or `""` when absent). Injected into every compiled module; `fallback_toml` is a reserved module name so a source file can never collide with it.

### 3.3 Registry shape enforcement

- `classifyFile` enforces exact `pub const module` spellings via comptime needles: typed (`pub const module: @import("contract").` ), segdraw (`pub const module = segdraw.module(`), and layout (`pub const module = tiling.layoutModule(`). Any other spelling is a loud build error, because a mis-typed member would silently break the registry.
- `deriveOwnerContracts` derives each owner's contract name from its declarations (empty → default contract, mixed → `error.MixedOwnerContract`). No hand-written table.

### 3.4 Layer purity enforcement

- `assertPureLayerImports` runs (via `wireAll`) on the real `@import` edges of every discovered module. For sources under `src/model/`, `src/tiling/`, and `src/config/`, each dependency is checked against `pureLayerAllows`:
  - the shared utility shelf — `constants, debug, ids, masks, utils, paths, proc, bounded, idmap`;
  - always `model`;
  - tiling may additionally import `tiling` and `contract`;
  - config may additionally import its siblings `parser, schema, types, fallback` and the pure `keysyms`.
  - Any other import (hub wiring, `xcb`) fails the build with `error.LayerGuardViolation`.
- This is complemented by `dev/scripts/check-layers.sh`, which sweeps import *bodies* for bare `xcb` tokens in pure-layer files (an import guard alone can't catch `xcb` re-exported through a shelf module). Its Rule 1 puts X mutations behind the sync seam (with a documented allowlist: `src/bar/bar.zig|src/bar/drawing.zig|src/bar/win.zig` for the bar's own wire lifecycle); Rule 2 does the same for server grabs; Rule 3, the body sweep.

### 3.5 Tests

- Unit tests run under `b.step("test", ...)`. `has_*` gates control which run in a given build (e.g. `model_test` needs `has_minimize and has_fullscreen and has_floating and has_workspaces`; `visibility_test` needs `has_bar`; `vim_test` needs `has_vim and has_seg_prompt`).
- X-gated integration tests chain on a shared `x_gated_run` step, serialized on a single `$DISPLAY`.
- A `check-plugin-template` build step compiles every `dev/plugin-template/` file against the real discovered modules (cross-wired in-tree) — the plugin contract always stays truthful.

## 4. The contract layer (`src/core/contract.zig`)

The pluggable-composition hub. Key contents:

- `Surfaces` — the chrome-surface (bar) interface; sole export of the generated `surfaces` module. Core can ask for a chrome surface without naming the bar subsystem.
- `WindowModule` — the flat, all-optional-hook interface for `src/window/modules/*`. Members: `init`, `deinit`, and hooks like `sendToWs`, `addToWs`, `removeFromWs`, `togglePin`, `toggleAllView`, `hideWindow`, `restoreWindow`, `coveringWsOf`, `toggleCovering`, `transferFullscreenOnMove`, etc. The registry binds them; dispatch helpers (`providerOf`, `callFirst`, `callFirstBool`, `callAll`, `callFirstTrue`) take the registry as a parameter so contract has no import edge into generated layers.
- `Layout` — the tiling hook set: `name`, `compute`, `variant_count`, `fifo_variant`, `variant_parse`, the scroll-viewport addons (`slotWidth`, `maxOffset`, `preReconcile`), and bar metadata (`icon`, `indicators`). The interchange vocabulary (`View`, `List`, `Placement`, `Env`, `HintsView`, `parked_rect`) lives here rather than in `tiling/`, so the always-compiled reconciler can name it even when zero tiling modules are present.
- Seam binding helpers: `contract.tiling_mods` — the single, shared `if (build_options.has_tiling) @import("tiling_modules").modules else &[_]Layout{}`.
- Serialization seams: `serializeWindow` (module claims a window blob; `persist` stamps registry ordinal + format version) and `deserializeWindow` (self-identification via magic byte).
- Dispatch family `providerOf`/`callFirst`/`callAll`/`callFirstTrue` shared by every registry family.
- `activeLayoutKind(kind)` — pure gate applied for the bar's layout/variant segments.

## 5. Core (`src/core/`)

### 5.1 `src/main.zig` — entry point

Boots the whole tree, in order: `core.init`, events/signals setup, `config.load`, input (`input.setup` → `input.initXkb` → `config.load` → `input.buildKeybinds`), surfaces/bar init, window/actions/pipeline init, then the event loop via `events.zig`. Orders deferred cleanups (`deinitKeybinds` before the config it borrows from is freed). Enables the Zig segfault handler and writes a crash log. It is the only place most subsystems are ever imported by name; everything else communicates through seams.

### 5.2 `src/core/core.zig` — process-wide XCB state

The connection singleton plus shared vocabulary: `XK` keysym enum, `Connection`/`Screen` aliases, `WindowId = ids.WindowId` (u32), `WorkspaceId = ids.WorkspaceId` (a `struct{index: u8}` wrapper), `FocusSuppressReason`. Re-exports the `xcb` cImport (as `core.xcb`) for the modules that need it. `core.init()` must complete before `getState()`; failure is fatal.

### 5.3 `src/core/pipeline.zig` — model owner + reconcile choke point

Owns the global `Model` instance (`pub var initialized`); builds the per-reconcile `sync.Ctx`; entry points `init()`, `dragTick()`, `reconcileNow()`, fullscreen hooks, `reconcileUnderGrabNow*` / `reconcileGrabFocus`. Model access is `*const` via `pipeline.model()` (compiler-enforced read-only); mutation requires the private `Gate` capability `pipeline.mut` — a zero-cost, accident-resistant pattern, and the reason tracking/window/actions/focus each declare their own private `gate` rather than a shared writable token. Runs `preReconcileDuties` (applies the scroll layout's `preReconcile` at the single choke point) and `tilingEnv` (resolves the config-driven `contract.Env` from config+scale). Imports `contract.tiling_mods` and `tiling_seam.tiling`.

### 5.4 `src/core/events.zig` — event loop + dispatch

X event dispatch and the main loop. Uses event-polling over `fd_xcb = 0` and the signal wake `fd_signal = 1`, batching `max_events_per_batch = 128`. Handles: mapping-notify (XKB rebuild → re-grab), config reload (`handleConfigReload`: load → reject parse failures or non-`.user` source → `validate` → XKB check → `input.buildKeybinds` pre-swap → atomic pointer swap → `refreshSnapshot` → `detectChanges` → per-subsystem gated work → re-grab), re-exec (`handleReexec`: pins `HANA_CONFIG_DIR`, persists state, `restart.execNext`), grabs (`grabKeybindings`, ungrab-all then re-grab every binding across all lock-modifier combos), and `setenv`/libc for the `HANA_CONFIG_DIR` hand-off. Mutual runtime-only circular dependency with input (no comptime cycle).

### 5.5 `src/core/persist.zig` — pure serialization

Serializes the model to a temp file via `std.json` — no X traffic. Carries a `WindowRecord` per window with a presence flag and an opaque extension blob stamped `[version][registry ordinal][payload]`, so window-owner modules claim their own blobs on restore. Mirrors `tiling` layout names via `config.canonicalLayoutName`. Serializes all `max_workspaces` workspaces; floats round-trip exactly. Restore is driven from `window.adoptRootWindows` + `applyModelLevel`.

### 5.6 `src/core/restart.zig` — re-exec coordinator

In-place `execv` of the same binary. Explicitly xcb-free and model-free; it only arranges the environment hand-off (`HANA_CONFIG_DIR` pinned to the frozen last-good config snapshot, `HANA_RESTORE`). Ownership split with `proc.zig`: `proc` owns the reload (SIGHUP / atomic flag + wake byte, no process swap); `restart` owns the re-exec (SIGUSR1 / `requestReexec`).

### 5.7 `src/core/scale.zig` — DPI detection/scaling

DPI probing via RandR + `RESOURCE_MANAGER` (`Xft.dpi`, 1024-word probe then 4096 retry), `mm_per_inch 25.4`, `baseline_dpi`, reasonable-DPI band 50–300, `font_baseline_height 1080`. Exposes `scaleFontSize`, `scaleBarHeight`, and `bar_min_height_px = 20`. Feeds font and bar sizing; its `XftProbe` distinguishes truncation from genuine property absence.

### 5.8 `src/core/screen.zig` — work-area ledger

Tracks which window claims screen edges (used by the bar). `Edge { top, bottom, left, right }`, `Claim { edge = .top, px = 0, active = false }`, `max_claims = if has_bar 1 else 0`, `bar_id = 0` — a comptime-fixed claims array. Chrome surfaces **push** claims and only **read** `workArea()`; `setSurfaceWindow` lets core recognize the bar window as chrome so it is excluded from margins.

### 5.9 The sync seam — `sync.zig` → `sink.zig` → `wire.zig` (+ `xcb.zig`, `masks.zig`)

The send architecture is a strict three-layer seam:

- **`src/core/sync/sync.zig` (planner, 588 lines).** The reconcile engine: computes the desired X state unconditionally and emits *only the delta* against a write-only sent ledger. `Ctx` bundles the `Sink`, screen rect, `workarea`, `cfg_bw`, env (`contract.Env`), and `color_of`. The `Stack` enum is `{ above }`. VTable: `map`, `geom`, `geom_bordered`, `border_width`, `border_pixel`, `park`, `stack_only`, `set_ewmh_fullscreen`, `flush`, `grab_server`, `ungrab_and_flush`. Calls `tiling.compute` (via the seam) to get placements; maps/parks are modeled as window-presence transitions. The four ledger reads are documented as a behavioral contract so future edits don't turn reads into skips. Id recycling (`forget`) keeps canvas-visible ids alive.
- **`src/core/sync/sink.zig` (dispatcher, 194 lines).** `XcbSink`, the vtable implementation over `wire.zig` primitives — the only home of mutations (with `wire.zig`; check-layers Rule 1).
- **`src/core/x11/wire.zig` (raw primitives, 328 lines).** Raw XCB request wrappers with batching/flush discipline. Poll-first reply collection, cookie handling. Imports `xcb` directly (not via core) so the graph stays acyclic — this breaks the historical `core → utils → wire → core` cycle. Comptime-driven atom cache: `supported_atoms ⊆ AtomCache` fields is enforced (`@compileError` on an advertised atom without a cache field).
- **`src/core/x11/xcb.zig` (16 lines).** The single `@cImport` translation site (`xcb.h`, `xcbext.h` for `xcb_poll_for_reply`, `randr.h`, `xkb.h` for detectable auto-repeat.
- **`src/core/x11/masks.zig` (102 lines).** X event-mask constants, used by grabs and window setup.

The grab protocol: `reconcileUnderGrabNow*` grabs the server, renders off-screen, queues blits **without** flushing, and `ungrabAndFlush()` sends configure-window + copy_area + ungrab in one flush — exactly one compositor frame per grabbed interaction.

### 5.10 The shared utility shelf (`src/core/utils/`)

X-free, fixed-capacity, single-threaded helpers reused across layers (and importable from pure layers):

- **`bounded.zig` (322)** — allocator-free collections: `BoundedList`, the sorted-key `bounded.Store` (used as the model's store). Capacity overflow refuses cleanly — no OOM error surface.
- **`constants.zig` (111)** — capacity/intent constants: `store_capacity = 128`, `mru_capacity = 16`, `max_tiled_per_ws = 64`, `max_workspaces`, `min_window_dim`, `offscreen_x_position`, `min_master_width`/`max_master_width`, `baseline_dpi`.
- **`utils.zig` (202)** — scaling helpers, `Rect`, `Margins`, `toXcbCoord`, the atom cache, EWMH helpers, monotonic timing, the `running` flag, `eventCast`.
- **`ids.zig` (39)** — `WindowId` (u32, xcb window), `WorkspaceId` (`struct{index: u8}`), `empty = 0` sentinel.
- **`idmap.zig` (137)** — keycode/window-ID ↔ index map; `idmap.empty = 0` non-zero sentinel.
- **`proc.zig` (87)** — the reload flag + wake pipe (config reload), plus path/waits.
- **`paths.zig` (54)** — XDG path resolution.
- **`debug.zig` (51)** — logging/diagnostics.

### 5.11 `src/core/signals.zig` — signal handling

Signalfd-based async signal handling (the `fd_signal` side of the event loop); bridges to `proc.reload()` (SIGHUP) and `restart.requestReexec()` (SIGUSR1). Fixed-capacity, no allocation.

### 5.12 `src/core/spawn.zig` — process spawn

Fork/exec/pipes for user actions (`exec`, keybind commands); drains child pipes, waits with timeout; `execSynchronous` for `,`-sequences. The user process lives outside the X model entirely.

## 6. The model (`src/model/model.zig`)

The single source of truth for management state. Pure, allocator-free, single-threaded, and **X-free by construction** — `assertPureLayerImports` forbids any imported hub/xcb dependency.

Key contents:

- Aliases/vocabulary: `WindowId`, `WSId`, `Mask = u64`, `bit(ws)`, `maskedOn`, `ALL_MASK` (the "all workspaces" pin sentinel), `SizeHints`, `RestoreOrder { lifo, fifo }`, `ConfigureReq`, `HonorDecision`.
- `LayoutParams` — kind (u8 registry index), `variant_idx`, `primary_width`, `primary_count`, `secondary_balance`, plus model-owned viewport state (`viewport_offset`, `viewport_prev_count`) so the layout engine stays pure.
- `BaseMode = union(enum) { tiled, floating: utils.Rect }`; `Presence = enum { present, parked, covering }`; `Entry` (mask, anchor, size_hints, `home_ws` single-membership cache, presence, `covering_ws`). The fullscreen "covering" record lives on the model entry itself.
- Collections are `utils.BoundedList` or `bounded.Store` (store 128, MRU 16, `max_tiled_per_ws` 64). Register/unregister roll back atomically on capacity refusal — no OOM paths.
- Predicates: `visibleOn`, `visibleEntry`, `taggedOn`, `isPinned`, `findHome` (cache-first home-workspace scan), `tiledCountOnWs`, `coveringOccupantOnWs`.
- Focus machinery: `setFocus`/`clearFocus` (MRU newest-first, oldest dropped), `fallbackFocusCandidate` (minimize-fallback policy across MRU → reversed tiled_order → any floating not in tiled_order, with `excluded` skip).
- Tiled-order primitives: `reorderTiled`, `stepTiled`, `swapPrimary`, `swapFocusedWithPrevious` (dwm-style rotate/swap), `adjustPrimaryWidth` (clamped to `min_master_width..max_master_width`).
- `applyConfigReload` — stamps a `LayoutParams` template across all workspaces preserving runtime viewport state (no spurious snap-right).
- Dependency direction: everything imports the model; the model imports only the shelf (`utils`, `bounded`, `constants`, `ids`).

## 7. Window subsystem (`src/window/`)

The lifecycle facade for managed clients. **No reparenting**: clients are direct root children; borders are drawn with the client's own X border width (`bw`). Windows are admitted on `MapRequest` or adopted on re-exec (`adoptRootWindows` from `persist`).

The layering chain: `model` (pure data) ← `tracking` (read facade) ← `window.zig` (facade + lifecycle) ← `actions.zig` (transitions) ← `focus`/`pipeline`/`sync` (protocol).

### 7.1 `src/window/window.zig` (1453 lines) — facade + lifecycle

Admission/teardown, geometry, size-hints, per-client `WM_CLASS`/`_NET_WM_PID` rules, `handle*` event dispatch (`EnterNotify`, `LeaveNotify`, `MapRequest`, `ConfigureRequest`, `UnmapNotify`, `ClientMessage`, `PropertyNotify`, `DestroyNotify`), WM_PROTOCOLS, spawn-queue workspace routing (`spawn_queue` cap 64; `child_cache` BoundedList of `ChildEntry`, cap 64). `rules_map` and `float_rules` route by WM_CLASS. Admission pipelines 5 property queries (`AdmissionCookies`: WM_CLASS, `_NET_WM_PID`, WM_NORMAL_HINTS, WM_PROTOCOLS, …) before map. Tracks `borders_flushed_this_batch`, `spawn_cursor`. All model mutation goes through its private `gate` (see 5.3).

### 7.2 `src/window/actions.zig` (1014 lines) — user-action dispatch

The single switch that executes user actions from input: `moveToWs`, `switchTo`, `cycleLayoutKind`, `stepVariantDir`, `toggleFloating`, `toggleFullscreen`, `swapPrimary`, master width/count, `growStack`, `toggleTag`, `applyConfigReload`, `seedParamsFromConfig` (the config → model seed seam, resolving `cfg.layout` via `tiling.layoutKindOf` with loud registry-0 fallback on unresolvable names), `applyRestoredLevel`, focus cycling (`cycle_focus`, `move_window_next/prev`), and the `scroll_view` viewport hooks. Calls into modules only via `providerOf`/`callHook` on the registry.

### 7.3 `src/window/focus.zig` (661 lines) — two-phase focus

`FocusTransition`, `prepareFocus`/`prepareClearFocus` (cache-only, non-blocking, outside the grab), `applyPendingFocus` (pure fire-and-forget inside the grab), MRU history bookkeeping, `drainTilingOpSettle` (suppresses transient focus noise during tiling operations). The two-phase split is a core grab-atomicity principle (5.9).

### 7.4 `src/window/tracking.zig` (190 lines) — read facade

Registry mapping X windows → model entries (with `setWorkspaceCount` fed by workspaces at init). No mutation capability; the read counterpart of admission.

### 7.5 `src/window/wincache.zig` (305 lines) — metadata cache

In-process cache of window name/class/icon/etc., populated at admission and invalidated on PropertyNotify — the source of title data for the bar (no X round-trips for bar content under a grab).

### 7.6 `src/window/borders.zig` (91 lines) — border reload

`CacheMap` with dedup; `updateWorkspaceBordersIfNeeded`, `reloadBorders` after config reload. Border geometry itself is applied through the sync seam, not here.

### 7.7 `src/window/icccm.zig` (349 lines) — ICCCM conventions

ICCCM/EWMH property handling, hints, `buildRulesMap` + `tryAddClassRule` (WM_CLASS → workspace/floating routing), WM_DELETE_WINDOW/`_NET_WM_PID` helpers.

### 7.8 `src/window/modules/` — window-owner plugins (the `window_modules` registry)

Each binds `module: contract.WindowModule`; delete a file and the registry shrinks, decocting hooks into no-ops. Nothing names a sibling module.

- **`floating.zig` (430)** — floating mode: float/toggle, drag interact (`dragTick`), work-area anchoring, float-negotiated geometry; the drag path feeds `pipeline.dragTick`.
- **`fullscreen.zig` (282)** — fullscreen: `covering` presence on the model entry, `toggleCovering`, `moveCoveringTo`, `retargetOrDropFullscreen`, cross-workspace ownership rules; the bar hides via `hideBarForFullscreen` (atomic with the enter grab).
- **`minimize.zig` (323)** — self-contained parked store: model records only `.parked`; restore order (`lifo`/`fifo`) is stamped by a monotonic saturating `g_seq`. Refuse-before-mutate (a failed restore leaves the window parked). Interim `.covering` coexistence; persistence blob magic-byte `0x5A`.
- **`workspaces.zig` (125)** — tag membership transitions + the workspace count forwarded to `tracking`. `sendToWs`/`addToWs`/`removeFromWs`/`togglePin`/`toggleAllView` as model transitions (mask + `tiled_order`). Out-of-range targets no-op everywhere (ReleaseFast OOB guard). Fullscreen-follows-move policy: the covering record transfers on tag move; a destination owner demotes the mover; last-tag-removal retargets to the lowest remaining bit. All model-state; the module holds no state after init.

## 8. Tiling subsystem (`src/tiling/`)

### 8.1 `src/tiling/tiling.zig` (345 lines) — dispatch engine

No XCB, no allocation. Re-exports the contract's interchange vocabulary (`Placement`, `parked_rect`, `HintsView`, `Env`, `View`, `List`) so modules keep short spellings. Owns `LayoutCtx`, `Region`, hints/geometry helpers (`applyHints`, `clampAspectDim`, `snapDimToIncrement`, `insetRect`, `outerArea`, `bisectRegion`, `paneCell`, `emitView`, `emitHidden`, `showOneHideRest`, `emitOverflowShare`), and the registry dispatch: `layoutByName`, `layoutKindOf`/`layoutKindFallingBack`, `moduleName`, `variantCount`, `cycleKind`, `compute` (guards range/empty, delegates to `tiling_mods[kind].compute`), `variantParse`, and `layoutModule` (binds a compute hook to registry metadata: name, icon, indicators, variant count/parse). `compute` must emit exactly one placement per window in `v.order` with the full set visible — a deterministic module contract. Always-compiled consumers reach it through `tiling_seam`; production callers: `sync.zig:312` (inside `reconcile`, skipped when a covering window owns the screen or tiling is absent), `pipeline.zig`, `actions.zig`.

### 8.2 `src/tiling/modules/` — layout modules (`tiling_modules` registry)

Each binds `pub const module = tiling.layoutModule(...)`; adding a file extends the registry, deleting one shortens it.

- **`master.zig` (330)** — master-stack with a column-major overflow grid; the most complex module. Water-filling `fillHeights` (pins windows whose `max_height` fits and redistributes; three deliberate rounding schemes), `fifo_variant = 1` signals the spawn-placement variant to actions, `variant_parse "lifo"/"fifo"`, indicators `[N]`/`=N=`. Stack boost (`secondary_balance`) applies only on the single-column path.
- **`leaf.zig` (71)** — BSP bisection of the longer axis 50/50; recursion keeps children inside the parent (`first + gap + second ≤ dim`); min_dim floor gate → overflow share; borders only at leaf nodes.
- **`grid.zig` (71)** — equal cells, rigid or relaxed variant (relaxed widens the partial last row); 3-column special case; indicators `[#]`/`[~]`.
- **`fibonacci.zig` (106)** — spiral; each window takes half the remaining area; recursion-free (pointer-passed `Region`); geometry-only (gap+border) overflow gate.
- **`monocle.zig` (34)** — stacks all windows fullscreen, shows topmost (`focusedElse` with tail fallback so the last-focused resurfaces on close), optional gaps variant.
- **`scroll.zig` (105)** — half-screen slots on a horizontal scrollable strip; registers the viewport addons `slotWidth` (single source of truth for viewport math), `maxOffset`, and `preReconcileHook` (grow-duty: snap-right when count grew, takes `LayoutParams` by value — a pure delta). Core detects "scroll in use" by `has layout provides these hooks`, not by name.

## 9. Input subsystem (`src/input/`)

- **`input.zig` (556)** — keyboard/mouse/pointer handling and the (mods, keysym) → `Action` dispatch map. Owns `xkb_state` and the `keybind_resolver` (here, not in config, because it needs live XKB state the pure config layer must not depend on). `handleKeyPress` normalizes mods, gives the chrome overlay first right-of-refusal (bar surface), then `executeAction` — a single switch routing each `types.Action` tag to `actions.*`/`focus.*`/`spawn`/`utils.reload`/`restart.requestReexec`/`surfaces`/`pipeline`. `,`-sequences run strictly, `+`-batches fan out; tiling ops run under `tilingOp` (suppress-focus → mutate → `focus.beginTilingOpSettle()`). Grabs `Super+Button{1..5}` across all lock-modifier combos; manual `XcbCursor`.
- **`keybind.zig` (81)** — keysym→keycode resolution + the `(mods << 32 | keysym) → *const Action` dispatch map (built via `KeybindResolver.rebuildDispatchMap`, O(1) `lookup` on the hot path). Lives in input (not config) to break the `types → xkbcommon → core → types` cycle and keep config X-free.
- **`keysyms.zig` (37)** — pure libxkbcommon keysym-name parsing; split out so the *pure* config layer can import it without pulling in the X-wired input stack. `pureLayerAllows` lists it as a config sibling.
- **`xkbcommon.zig` (279)** — XKB state: flat `[x11_max_keycode]u32` table (1 KiB, no heap), detectable auto-repeat via `XkbPerClientFlags`, startup retries (`max_xkb_retries = 3`) + keymap health checks, mapping-change rebuilds that swap the table only after a successful new keymap — failure keeps the old mapping so dispatch never dies.

## 10. Bar subsystem (`src/bar/`)

The bar is an orchestrator with zero segment logic: every segment is a drop-in addon bound into the generated `bar_modules` registry and consumed through `contract.Segment`. The bar never names a segment module; services flow one-way through `segmod.BarHandlers`. Chrome overlay (title/prompt) pre-empts keypresses.

### 10.1 Infrastructure (`src/bar/` root)

- **`bar.zig` (1910)** — the orchestrator. Window lifecycle (create/map/strut/colormap), the layout pass (left → center → right), click dispatch, per-segment **dirty tracking** (`Dirty { flag, segments: [bar_mods.len]bool }`, whole-bar full-redraw flag, `span_x`/`span_w` consumed by the region copy), the grab-scoped redraw path, screen-claim sync, prompt-visible forcing. Constants: `min_bar_height 20` (from scale), `max_bar_height 200`, `default_bar_height 24`, `max_frame_windows = segmod.max_visible_windows`, `max_click_bounds = bar_mods.len`, `max_right_segments 16`, `max_batched_redraws 4`. Maps the window *before* the first draw (blits to unmapped windows are discarded; compositors start remapped blank). `g_bar_handlers` is a module global on purpose — the prompt retains the pointer past init (use-after-return hazard documented). `pollTimeoutMs` returns −1 when hidden (a hidden bar can't make progress, suppressing carousel spin/caret blink re-arming).
- **`segment.zig` (324)** — the shared frame/window vocabulary: `DrawCtx`, `Frame`, `Row`, `Canvas`, `Visibility`, `Dirty`, `BarHandlers`, workspace-frame mirror fields, `MinimizedApi` (synthetic hide-set route that stays build-gated on `has_minimize`), `findAllByCapability` (comptime capability scan), `castDraw`, populating clip windows, `recordClickBound`.
- **`segdraw.zig` (127)** — comptime module builder for simple draw+onClick addons: `module(name, draw, on_click, opts) → contract.Segment`, `Opts { with_collapse, self_ticking, clickable, pollTimeoutMs, secondsElapsed, invalidate, invalidateReloadCaches, measureString, natural_width, on_click }`. `with_collapse` preserves the previous segment's span when width → 0 (no flicker).
- **`drawing.zig` (971)** — all Cairo/Pango rendering: draw-context creation, font-list building, `drawText(Ellipsis)`, `drawPaddedSegment`, `toCairoColor`, `clockFormat` (shared accessor for clock/title/systatus), and the two blit paths — `queueBlit` (batch-end, grab-safe, no flush; trusts its window is fully drawn) vs `blitRegion` (flushes immediately; timer paths only, never mid-batch — it would snapshot stale siblings).
- **`metrics.zig` (44)** — the effective DPI-scaled font size (`getScaledFontSize`/`setScaledFontSize`, `recompute` tying into `scale.scaleFontSize`), kept near its only reader (`drawing.buildSizedFontList`) and writer (`bar.calcBarHeightAndFontSize`).
- **`refresh.zig` (329)** — adaptive RandR refresh-rate detection (`detectedHz()`, atomics, `ensureRefreshRateDetected` idempotent, `handleRandrNotifyEvent` hook, `runPendingRedetect` consumed outside event dispatch so detection never blocks the loop). Drives the carousel's frame cadence.
- **`visibility.zig` (64)** — *pure* visibility policy, no X11/wire code: `desiredVisibility(ws, is_visible, is_globally_visible)`, fullscreen forcing (comptime-folds false without `has_fullscreen`), and the `keepPromptOverride` recomputed at prompt-exit so granted visibility can't be gamed by toggles while visible.
- **`win.zig` (186)** — the bar's own window wire lifecycle: `createWindow` (depth-32 ARGB visual + colormap), `setWindowProperties` (`_NET_WM_WINDOW_TYPE_DOCK`, `_NET_WM_STATE_ABOVE`|`STICKY`, `_NET_WM_STRUT_PARTIAL`, `_NET_WM_ALLOWED_ACTIONS`), top/bottom positioning, free/atom helpers. One of the three allowlisted files authorized by check-layers Rule 1 to configure/map/change-attributes outside sync.

### 10.2 Segments (`src/bar/modules/`)

- **`clock/clock.zig` (236)** — self-ticking clock (`self_ticking = true`, `pollTimeoutMs 1000`), `DisplayMode` cycling (`cycleDisplay`: left advances, right reverses), per-mode width probes.
- **`tags/tags.zig` (230)** — workspace tags with active indicator, per-workspace icons/labels (`getLabel`), `invalidate()` on font/icon reload; click toggles workspace.
- **`layout/layout.zig` (40)** — active tiling-layout icon (`getIcon` from the model + `contract.activeLayoutKind`; `fallback_icon "><>"` when tiling is absent — everything floats).
- **`layout/variants.zig` (49)** — active layout variant string; 0-width slot when the active layout has no variant (`no_variant_icon = ""`), `with_collapse = true` so it appears/disappears without flicker.
- **`systatus/systatus.zig` (216)** — iterates the generated `systatus_subs` registry of simple readouts, coalesced to `read_interval_ms 2000`, throttled, `max_readout_len 36`, `needsRepaint` false while contents unchanged.
- **`systatus/batt.zig` (37)** — first `/sys/class/power_supply/BAT*` charge %; renders nothing (collapses) on battery-less machines.
- **`systatus/cpu.zig` (62)** — aggregate core utilization from the `/proc/stat` first-line delta; first read is the boot-cumulative average while the baseline is established.
- **`systatus/mem.zig` (49)** — used % from `MemTotal` vs `MemAvailable`; saturating math; unit test in-file.
- **`title/title.zig` (522)** — the center-slot title chrome overlay: tracks focused-title identity, renders text, and hosts the inline prompt overlay (found by scanning `bar_mods` for the `BarOverlay` hook — name-free). Click-to-focus, right-click toggles the chrome overlay, `TitleWidthMemo` (buffer-content compare avoids stale width on X id reuse). First center-slot binder = the title.
- **`title/carousel.zig` (145)** — marquee scroller for the title, advancing one display period per frame locked to `refresh.detectedHz` (sub-pixel f32 offset handed to cairo); `inter_title_gap_px 48`; `resetForShow` prevents advancing across the hidden gap.
- **`prompt/prompt.zig` (1388)** — the inline command prompt overlay (chrome-overlay client; the largest single file): full line editor, insert/normal modality (vim module separate), command completion (files + history), spawn action. Addons via `prompt_subs` registry (`Addon { register, init, deinit }`). Ghost-append drawing inline in `performDraw` — deliberately not `blitRegion` (mid-batch copy would snapshot stale siblings).
- **`prompt/vim.zig` (495)** — Vi-style modal editing over the *same* generic prompt buffer (no duplicate model): `dd/cc/yy`, `p/P`, `~`, `f/t/F/T`, `%`, `..` repeat, `^/0/$`, word/paragraph motions, `MAX_MOTION_LEN` deque. Registered as the prompt's vim-mode addon.
- **`slider/slider.zig` (596)** — generic slider subsystem (brightness/volume): scroll stepping, preview-and-commit semantics, spawn/native commit throttle. Spawn commits (fork+exec+pipe blocking the WM loop ~1–5 ms) are cadence-throttled to `max_cadence_ms 5000` and coalesced to the *newest* value; **native** commits (`commit_is_native`) bypass the throttle and run immediately. Display always follows optimistic `preview`; the commit path re-reads.
- **`slider/brightness.zig` (409)** — sysfs (preferred) or `brightnessctl` backend, `Backend { unknown, sysfs, brightnessctl }`, `Class { backlight, leds }`, device pin (default `intel_backlight`); permanently flips to spawn backend on the first denied sysfs write.
- **`slider/volume.zig` (302)** — backend probe order: native Pulse (dlopen) → pactl → native ALSA → amixer; `VOL {pct}%`/`MUTE`; mute toggle.
- **`slider/native_alsa.zig` (362)** — direct ALSA mixer ioctls on `/dev/snd/controlC*` — no libasound dependency; structs pinned to the ioctl ABI; activates only when no PulseAudio runtime is present.
- **`slider/native_pulse.zig` (574)** — PulseAudio via `dlopen("libpulse.so.0")` (no link dependency); stable `pa_sink_info` layout offsets handled by tables for pulse ≥ 16 and pre-16; bounded waits under the mainloop lock; any failure abandons to the spawn fallback.
- **`systatus`/`slider` sub-registries** are build-generated from file presence — adding a readout or backend is literally dropping a file.

### 10.3 Cross-cutting bar invariants

1. The bar never names a segment — everything routes through `bar_modules` + `contract.Segment` dispatch; `BarHandlers` is the one-way service flow.
2. Visibility is pure policy ($10.1 `visibility.zig`) with wire glue in `bar.zig`.
3. Grab protocol: grab → off-screen render + queued copy_area → single `ungrabAndFlush` — one compositor frame, no intermediate flushes.
4. Native audio paths bypass the spawn throttle; only fork/exec-style commits are cadence-throttled and coalesced.
5. Buffering is comptime-capped; overflow degrades gracefully (over-wide desktops clamp the right cluster, extra segments lose clickability) — no UB in ReleaseFast.
6. `max_*` constants (`max_frame_windows`, `max_click_bounds`, `max_right_segments 16`, `max_batched_redraws 4`, `max_outputs 64`, `default_max_input 256`, `max_readout_len 36`, `battery_probe_slots 8`) are the buffer-rightsizing philosophy in action.

## 11. Config subsystem (`src/config/`)

A three-layer interpreter split — tokenizer/parser → comptime schema for scalars → hand-written structural interpreters — over a strict, acyclic dependency chain: `types` ← `parser` ← `schema` ← `config`, with `fallback` reading only the generated `fallback_toml`. Config is pure and X-free by construction (it may read files/env but performs no X calls).

- **`types.zig` (761)** — the single source of truth for schema **types and defaults**: `types.Config{}` is a complete valid config. Contains the `Action` union (25+ variants — the shared command vocabulary carried by both keybinds and mouse-binds), `ScalableValue` (f32 value + `is_percentage`), `Color = u32`, `Keybind`/`MouseBind`, `TilingConfig` (canonical `layout = "master"`, last-wins `workspaceLayoutLookup`/`masterCountLookup`), `BarConfig` (large), `Rule`, `WorkspaceConfig`, section-name constants, `max_config_name = 32`, `lowerSlice`, `enumFromString` (comptime string_map lookup), free helpers parameterized by `keep_capacity` to serve both reload repopulation and teardown. Imports only the shelf + `model` — no parser (breaks the cycle) and no X.
- **`parser.zig` (1251)** — the hand-rolled TOML-ish tokenizer/interpreter → arena-borrowing `Document`/`Section`/`Value` (`integer/boolean/string/array/color/scalable`). Cross-file merging, "later declaration wins" scalars + full array accumulation, a document-global color palette with fixpoint alias/`+`-mix resolution (`resolveColorExpr`, `max_mix_operands 8`), deterministic `keys_in_order`/`lines_in_order` diagnostics, warn-and-skip with `had_errors` (never crash; the facade fails the whole load on errors), stacking limits against pathological input. Owns everything (strings alias `content`); no deinit.
- **`schema.zig` (792)** — the comptime knob table: ~60 `Knob` entries (placement, dotted config target path, value `Kind`, gating) collated by comptime builders, plus generic warn-and-revert readers and `applyAll` (table-driven scalar interpretation, replacing hand-written scalar code). `Kind`: `b`, `int{min,max}`, `scalable`, `scalable_free`, `auto_scalable`, `color`, `color_from`, `ratio`, `str`, `enum_read`. Ranges warn-and-revert (never clamp; guards the `@intCast` trap); ratios reject outside [0,1] with the bare-`1` = 1% ambiguity warning; colors decode through the single `parser.colorFromValue` + mix + palette layers; layout names are canonicalized (grammar-tested) and resolved against the registry at seed time. `bar_properties_knob_keys` derived at comptime.
- **`fallback.zig` (74)** — exposes the build-embedded default TOML (`fallback_toml.content`, empty ⇒ absent) and auto-detects a terminal (`detectTerminal()`, preference list ghostty→…→xterm) to stitch into `auto_terminal` keybinds. The only config file that touches the environment, and the only consumer of `fallback_toml`.
- **`config.zig` (1923)** — the facade and interpreter: load pipeline (`load` → `loadConfigDefault` with priority `HANA_CONFIG_DIR` env → `~/.config/hana/` → `./config/` → single-file paths → embedded fallback), arena-scoped parse+merge then owned-Config materialization, `validate` (domain rules like master-width ratio vs pixel), `canonicalLayoutName` (folds `master-stack`/`master_stack` → `master`, shared with persist), the non-scalar interpreters (`parseKeybindings` via a comptime `action_map`, `parseTilingStructures`, `parseBar`, `parseRules`), `detectChanges(old, new) → ConfigChanges{bar, tiling, keys}` (hand-maintained field lists with logical-content map comparison; `keysChanged` compares only the pair layout, excluding the action), `refreshSnapshot` (freezes last-known-good config into `$XDG_RUNTIME_DIR/hana-config` / `/tmp/hana-config-<uid>`; runs only after a successful load), `reexecSnapshotPathZ` (one-shot NUL-terminated for `setenv`). Fail-closed: `doc.had_errors` ⇒ `ConfigParseFailed`; boot falls to the embedded fallback; reload keeps the live config; re-exec never boots on a mid-edit config.

### 11.1 Config → runtime flow

Boot: `main` → `config.load` → `actions.seedParamsFromConfig` (resolves canonical layout names and variant strings through the active layout module's own `variant_parse`) → `model.applyConfigReload` (viewports preserved) → first reconcile. Reload (`reload_config` keybind / SIGHUP → `proc.reload`): swap config, gate per-subsystem work on `detectChanges` — `surfaces.onReload()` for bar, `actions.applyConfigReload` + `window.reloadBorders` + `buildRulesMap` for tiling, regrab for keys. Re-exec (`reload_hana` / SIGUSR1 → `restart`): `setenv("HANA_CONFIG_DIR", snapshot)` then `execv`, so only the binary swaps; config edits land exclusively through `reload_config`.

## 12. Cross-cutting themes

- **Grab-atomic transitions.** Every user action funnels through the pipeline into `reconcileUnderGrabNow*`/`reconcileGrabFocus`, keeping focus protocol + geometry + borders + EWMH under one server grab with fire-and-forget XCB inside and exactly one flush at the end (bar chrome included — off-screen render, queued blit, `ungrabAndFlush`).
- **Unconditional compute, delta send.** The sync ledger makes full recomputation cheap; the send is always the diff. Reads of the ledger are a documented behavioral contract.
- **Pure by law.** Model/tiling/config may not import the hub or `xcb`; two independent enforcement mechanisms (`assertPureLayerImports` on import edges at build time, `check-layers.sh` on source bodies) make it structurally impossible, not just a convention. `pureLayerAllows` even handles the special cases (`keysyms` for config, `tiling`+`contract` for tiling).
- **Deterministic, allocation-free. Fixed capacities and refuse-before-mutate everywhere; overflow degrades gracefully rather than panicking or allocating.
- **Name-free optional subsystems.** The core names optional subsystems through generated seams only; dispatch loops iterate registries; capabilities are detected by hook presence, never by naming a module (`with_collapse`, `self_ticking_ids`, "scroll in use" = viewport hooks present, prompt overlay = `BarOverlay` hook found by scan).
- **Fail-closed reliability.** Broken config never partially loads; input keeps the last good keymap on XKB failure; the bar maps before first draw; snapshots are last-known-good; restart snapshot chain guarantees a backup configuration.
